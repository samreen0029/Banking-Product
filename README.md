# Crescendo Banking Dashboard

I created a simple and modern banking dashboard using **HTML, CSS, and JavaScript**.

This project helps users view their banking products, including savings accounts, credit cards, personal loans, and investments.

### Technologies Used
- **HTML5:** Used to create the structure of the webpage.
- **CSS3:** Used for styling, layouts, colors, and responsive design.
- **JavaScript:** Used to add interactive features like product search, category filters, and product details.

### Features
- Product overview
- Search and filter options
- Interactive product details
- Responsive user interface
